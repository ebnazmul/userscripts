# Userscripts Collection

This repository contains my collection of userscripts for improving workflow, automation, and UI enhancements across different platforms.

## 📂 Structure

Scripts are organized by purpose and platform inside their respective folders.

## 🚀 Usage

1. Install a userscript manager like:
   - Tampermonkey
   - Violentmonkey

2. Add the desired script from this repository.

3. Enable the script and use it on the supported website.

## 🛠️ Scripts Included

- Chat helpers
- UI enhancements
- Automation tools

*(More scripts will be added over time.)*

## 📌 Notes

- Scripts may require specific websites to function.
- Always review scripts before using them.
